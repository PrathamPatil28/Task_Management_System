# 📢 Project Management System – Built for Productivity, Powered by Tech!

Managing tasks, teams, and timelines shouldn't be chaotic. That’s why I created a **modern, efficient, and secure Project Management System** to help teams stay organized and in sync. ✅

Whether you're a freelancer, startup, or growing team – this tool is designed to **simplify your workflow and boost productivity**. 💼✨

---

## 🔧 Tech Stack Breakdown

### 🔹 Frontend:
- ⚛️ **React + TypeScript** – For a fast, scalable, and interactive UI  
- 🧩 **ShadCN UI** – Sleek, modern components with built-in dark mode  
- 📦 **Redux Toolkit** – Powerful state management, smooth UX  
- 💳 **Razorpay Integration** – Seamless payment processing for premium features  

### 🔹 Backend:
- 🚀 **Spring Boot** – Robust APIs & efficient backend architecture  
- 🗃️ **MySQL** – Reliable data storage and task tracking  
- 🔐 **JWT Authentication** – Secure user access & session management  

---

## 🌟 Key Features

- ✅ Task & Project Management  
- ✅ Team Collaboration & Member Assignment  
- ✅ Secure Login with JWT Authentication  
- ✅ Payment Gateway Integration via Razorpay  
- ✅ Clean, responsive UI with full **dark mode** support  
- ✅ Real-time updates and smooth user experience
